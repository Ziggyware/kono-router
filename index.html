🔨 Forge a tool 📖 format docs
Name
Lowercase letters, digits and underscores · up to 64 characters · must not reuse a built-in tool's name. Forging a name that is already forged replaces that tool.
Description
One or two concrete sentences: what it does, what goes in, what comes back. This is the main signal models use to choose tools — vague descriptions get skipped.
Parameters — JSON Schema
The arguments object schema. Build it with the controls or edit the JSON directly — whichever you change, the other follows. Extra schema features the controls cannot show (enums, nested item schemas) are preserved, never deleted. The router validates every call against this before the code runs. Full spec: forge format docs.
Code — JavaScript body
An async function body. It receives args (validated against the schema above) and api — fetch, kv, namespace, signal, now. Whatever it returns becomes the tool result. Deno, process and globalThis are not available inside. Max 16 KiB, default 4 s deadline.
Forging needs the admin secret from connection settings. The tool goes live in the registry immediately and persists across restarts. The ✦ AI notch on each field can explain it, draft it, or fix it.
